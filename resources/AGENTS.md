# Resource Manifest Instructions

## Scope

- This top-level directory stores resource manifests and tiny redistributable
  mapping fixtures, not downloaded knowledge-base payloads.

## Manifest Contract

- Record resource ID, release/version, species, gene namespace, source URL,
  SHA-256 checksum, license, citation, retrieval date, adapter version, and any
  transformations.
- Review redistribution rights before adding a fixture.
- A resource update requires a change note and compatibility/benchmark impact
  assessment.
- Never commit credentials, cache directories, full OmniPath/NicheNet payloads,
  or derived patient data.
