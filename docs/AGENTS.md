# Documentation Instructions

## Scope

- Own versioned concepts, mathematical methods, API guides, tutorials, ADRs,
  release notes, statistical limitations, and reproducibility instructions.

## Rules

- Restore damaged equations from `../prompt.md` through independent derivation
  and review before treating them as normative.
- Clearly label implemented, experimental, and planned behavior.
- Define inferential versus exploratory output and distinguish strength,
  probabilities, effects, and q-values in every relevant guide.
- Examples use synthetic or redistributable data, fixed seeds, pinned resource
  versions, and commands that are exercised in CI.
- Claims about calibration, performance, or clinical utility link to a
  versioned benchmark/release report.
